# MinerBot v13 · Meta mensual de subs

- Agrega una meta de subs mensual al mismo Browser Source global de OBS.
- El contador se actualiza con subs nuevas, renovaciones y gifts de Kick.
- Se reinicia automáticamente al cambiar de mes (zona horaria Argentina/Buenos Aires).
- El contador actual y la meta son editables desde Dashboard > Meta subs.
- Tamaño y posición del overlay son editables.
- Corona y Meta subs ahora usan fondo negro + borde blanco fino.
- No requiere una migración D1 nueva: usa `streambot_settings`, que ya existe.

Después de desplegar, abrí el dashboard, guardá la meta deseada y refrescá la Browser Source de OBS una vez.
